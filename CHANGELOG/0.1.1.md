### 1.2 `DAMAGE_RECEIVE_LAST_HIT` — FLAG de changement d'état

**Avant :**
```python
# Interprété comme une valeur de dégâts absolue
damage_dealt = state['damage_last_hit']
reward += damage_dealt * 0.1
```

**Après :**
```python
# ✅ C'est un FLAG : seul le changement de valeur signifie un coup reçu
def detect_damage_hit(self) -> bool:
    current_flag = self.read_value('DAMAGE_RECEIVE_LAST_HIT')
    has_changed  = current_flag != self.prev_damage_flag
    self.prev_damage_flag = current_flag
    return has_changed
```

---

### 1.3 `SHARPNESS` — int2 confirmé (2 bytes)
```python
SHARPNESS = 0x9014B0AC  # int2 (2 bytes) — 150 max, diminue à chaque coup

L'inférence automatique `int4` introduite temporairement en cours d'alpha
est retirée — l'auto-détection par nom de clé retourne correctement `int2`.

```

**Après :**
```python
# ✅ Type explicite int2 pour tous les slots
def _infer_type(self, name: str) -> str:
    if 'slot' in name.lower():
        return 'int2'
    if 'underwater' in name.lower():
        return 'int2'
    if 'sharpness' in name.lower():
        return 'int2'
    if 'hp' in name.lower() or 'damage' in name.lower():
        return 'float'
```

## 🎮 4. Système de récompenses

### 4.1 Pénalité menus
```python
# Ouvrir le menu Wii (action 14)
self.PENALTY_MENU_WII_OPEN          = 50.0   # Malus à l'ouverture
self.PENALTY_MENU_WII_PER_SECOND    = 10.0   # Malus par seconde passée dedans

# Ouvrir le menu in-game (action 13 + quest_time figé)
self.PENALTY_MENU_GAME_PER_FRAME    = 0.2    # Malus continu par frame (~-6/s à 30FPS)

# Exemple : rester 5s dans le menu Wii = -50 (ouverture) + -50 (temps) = -100 total
```

Détection du menu via temps figé :
```python
# Si action 13 ET quest_time identique au step précédent → jeu en pause → menu ouvert
if action == 13 and (quest_time - prev_quest_time) == 0:
    reward -= self.PENALTY_MENU_GAME_PER_FRAME
```

---

### 4.2 Bonus exploration
```python
self.BONUS_EXPLORATION_PER_UNIT = 0.05   # Par unité de distance parcourue
self.PENALTY_STATIONARY         = 0.01   # Par frame immobile après 30 frames

distance = np.sqrt((x-px)**2 + (y-py)**2 + (z-pz)**2)

if distance > 0.1:
    reward += distance * self.BONUS_EXPLORATION_PER_UNIT
elif frames_stationary > 30:
    reward -= self.PENALTY_STATIONARY
```

---

### 4.3 Pénalité camp prolongé

Appliquée toutes les 10 secondes après 30 secondes passées en zone 0 (camp).
Augmente par paliers de 30 secondes supplémentaires. Plafond à -30.
```
Temps en camp  → Pénalité par tranche de 10s
  30s - 60s   → -5
  60s - 90s   → -7
  90s - 120s  → -9
  ...          (max -30 par épisode)
```

---

### 4.4 Sharpness — Détection rebond
```python
sharpness = current_state.get('sharpness')

if sharpness == -2:
    reward -= 5.0   # Rebond : arme trop émoussée, coup inefficace
    logger.warning("Bounce detected — weapon too dull")

if 0 <= sharpness <= 30:
    reward -= 0.5   # Tranchant bas : pénalité continue légère
```

---

### 4.5 Dégâts infligés aux monstres

Détection dynamique — s'adapte au nombre de monstres présents :
```python
# Small monsters (SMONSTER1_HP, SMONSTER2_HP, ...)
for i in range(1, 5):
    key = f'smonster{i}_hp'
    current_hp = current_state.get(key)
    if prev_hp is not None and current_hp < prev_hp:
        damage = prev_hp - current_hp
        reward += 3.0 + damage * 0.05

# Large monsters (LMONSTER1_HP) — récompense doublée
for i in range(1, 2):
    key = f'lmonster{i}_hp'
    if prev_hp is not None and current_hp < prev_hp:
        damage = prev_hp - current_hp
        reward += 6.0 + damage * 0.10
```

## 🔄 5. Gestion automatique des épisodes

### 5.1 Auto-reload save state (F5)

Recharge automatiquement la save state 5 sans intervention manuelle :
```python
def _should_reload_save_state(self, current_state: dict) -> bool:
    quest_time  = current_state.get('quest_time')
    death_count = current_state.get('death_count', 0) or 0

    if quest_time is not None and quest_time <= 10:
        return True   # Quête expirée ou reset
    if death_count >= 3:
        return True   # Trop de morts dans cet épisode
    return False

def _reload_save_state(self):
    self.keyboard.press(Key.f5)
    time.sleep(0.1)
    self.keyboard.release(Key.f5)
    time.sleep(2.0)   # Attente chargement
```

### 5.2 Compteurs épisode corrects
```python
# Compteurs distincts (évite la confusion steps épisode vs steps totaux)
self.episode_count  = 0   # Épisodes depuis le début
self.episode_steps  = 0   # Steps dans l'épisode courant (reset à chaque reset)
self.total_steps    = 0   # Steps totaux cumulés

# À chaque reset()
self.episode_count += 1
self.episode_steps  = 0

# À chaque step()
self.episode_steps += 1
self.total_steps   += 1

# Transmis dans info
info = {
    'episode':       self.episode_count,
    'episode_steps': self.episode_steps,
    'total_steps':   self.total_steps,
    'current_zone':  raw_memory.get('current_zone'),
}
```
