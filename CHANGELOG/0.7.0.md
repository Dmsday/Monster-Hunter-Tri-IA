# 🔧 CHANGELOG - v0.7.0

## 📋 Résumé

**Réarrangement majeur de `train.py`.** L'ancien fichier monolithique de +4500 lignes est décomposé en un package `./train/` avec des modules spécialisés. `train.py` ne fait plus que quelques dizaines de lignes.

---

## ✅ 1. Avant / Après — Structure des fichiers

### Avant (v0.6.x)
```
train.py     # +4500 lignes : CLI, Dolphin, environnements, agents,
             # callbacks, training loop, multi-agent, cleanup...
             # Impossible à maintenir, tout couplé
```

### Maintenant (v0.7.0)
```
train.py             # ~20 lignes (entry point uniquement)
train/
├── __init__.py
├── __main__.py      # python -m train → runner.main()
├── runner.py        # Orchestrateur principal (setup → train → save → cleanup)
├── cli.py           # argparse : tous les arguments
├── dolphin.py       # Lancement/arrêt Dolphin, PIDs, signal handlers
├── environment.py   # Création des environnements (single/multi/VecNormalize)
├── agents.py        # Création/chargement agents (single/multi, clone/merge)
├── allocation.py    # Allocation agent ↔ instance (1:1, N:M, partage)
├── callbacks.py     # SB3 callbacks (GUI, checkpoints, exploration)
└── logging_setup.py # Création loggers, reconnection, config session
```

## ✅ 2. `train.py` — Entry point minimal

## ✅ 8. `_final_cleanup()` — Ordre de nettoyage garanti

```python
# train/runner.py — always-runs dans le finally block
def _final_cleanup(args, env, gui, allocation_result, training_loggers=None):
    # 1. Silencer frame_capture warnings
    # 2. Release controller inputs (un poll cycle avant de tuer Dolphin)
    # 3. Cleanup controller resources (shared memory)
    # 4. Close environment (arrête les threads capture)
    # 5. Kill Dolphin (safe : plus de threads actifs)
    # 6. Nettoyer PID files
    # 7. Restaurer log level frame_capture
    # 8. Close training loggers (session_summary, errors.log)
    # 9. Close GUI
    # 10. os._exit(0) pour garantir la sortie propre
```

## 📊 Impact

### Avant v0.7.0
- `train.py` : +4500 lignes, tout couplé, impossible à tester unitairement
- Chaque modification risquait de casser autre chose
- Impossible d'importer une fonction sans importer tout le reste

### Après v0.7.0
- Chaque module fait une seule chose (SRP)
- `train.py` lisible en 20 secondes
- Tests unitaires possibles par module
- Imports rapides et ciblés
