## ✅ 1. Hyperparamètres PPO adaptés au MultiDiscrete (28K combinaisons)

### Problème
Les valeurs par défaut de SB3 (`ent_coef=0.01`, `batch_size=64`, `n_steps=2048`) étaient calibrées pour des espaces d'action simples. Avec `MultiDiscrete([5,5,5,2,3,8,2])` = ~28 000 combinaisons possibles, l'agent convergeait trop vite vers NOOP sans explorer les actions de combat.

### 1.1 `ppo_agent.py` — Defaults de `create_ppo_agent()`

**Avant :**
```python
def create_ppo_agent(
        environment_new,
        learning_rate: float = 2.5e-4,
        n_steps: int = 2048,
        batch_size: int = 64,
        ent_coef: float = 0.01,
        ...
):
```

**Après :**
```python
def create_ppo_agent(
        environment_new,
        learning_rate: float = 3e-4,  # Faster initial convergence for 28K action combos
        n_steps: int = 4096,           # More rollout data per update
        batch_size: int = 512,         # Larger batches for stable gradient estimates
        ent_coef: float = 0.03,        # Higher entropy for 7-head MultiDiscrete — prevents early convergence to NOOP
        ...
):
```

## ✅ 2. Système de recovery save state avec copie cross-user

### Problème
Tous les 3-4 épisodes, un agent corrompt sa save state pour une raison inconnue. Le slot primaire (F5) contient soit une quête expirée, soit un MAP invalide. L'agent boucle indéfiniment sur l'écran de résultat.

### Solution — Pipeline de recovery en 3 phases (non-bloquant)

L'ancien système (v0.5.6) essayait tous les slots d'un coup dans `_reload_save_state()`, bloquant tous les autres agents pendant la recherche. Le nouveau système est **lazy** : un seul slot par appel, appelé périodiquement depuis le trainer sans bloquer les autres.

### 2.1 Phase 1 : Slot primaire (fast fail)

**Fichier : `episode_mixin.py`**

**Avant :**
```python
# v0.5.6 — Bloquant, essaie tout en une fois
def _reload_save_state(self):
    slots_to_try = [self.save_state_slot] + FALLBACK_SLOTS
    for slot in slots_to_try:
        result = self._verify_reload(attempt, max_attempts)
        if result == 'expired':
            continue
        if result is True:
            return True
    raise RuntimeError("All save state slots exhausted")
```

**Après :**
```python
# Non-bloquant : max 2 tentatives sur le slot primaire, puis return False
def _reload_save_state(self):
    """Only tries the primary slot (2 attempts) to avoid blocking
    other agents. If primary fails, returns False immediately
    and the caller should isolate this env + init fallback recovery."""
    slot_key = f'f{self.save_state_slot}'
    max_attempts = 2

    for attempt in range(1, max_attempts + 1):
        if not self._send_save_state_key(slot_key):
            return False
        self.save_state_reload_count += 1
        time.sleep(1.5)
        result = self._verify_reload(attempt, max_attempts)
        if result is True:
            return True
        if result == 'expired':
            return False  # → caller isolates + starts lazy fallback
        if result is False:
            return False
    return False
```

### 2.2 Phase 2 : Fallback local (un slot par appel, lazy)

**Fichier : `episode_mixin.py`**

```python
# NOUVEAU — Initialisation du fallback recovery
def _init_fallback_recovery(self):
    """Initialize state for lazy (one-slot-per-call) fallback recovery."""
    self._fallback_queue = [
        s for s in FALLBACK_SLOTS if s != self.save_state_slot
    ]
    self._failed_slots = [self.save_state_slot]
    self._fallback_cross_user_pending = True  # try cross-user after local slots
    self._last_recovery_attempt = 0.0

# NOUVEAU — Un slot par appel (appelé toutes les 5s par le trainer)
def _attempt_next_fallback(self) -> str:
    """Returns 'recovered' / 'pending' / 'exhausted'."""
    self._last_recovery_attempt = time.time()

    # Local fallback slots (F6 → F7 → F8)
    if self._fallback_queue:
        slot = self._fallback_queue.pop(0)
        self._send_save_state_key(f'f{slot}')
        time.sleep(2.0)
        result = self._verify_reload(attempt=1, max_attempts=1)
        if result is True:
            self._propagate_working_save_state(slot)  # Copy to failed slots
            return 'recovered'
        self._failed_slots.append(slot)
        return 'pending' if (self._fallback_queue or self._fallback_cross_user_pending) else 'exhausted'

    # Cross-user recovery (phase 3)
    if self._fallback_cross_user_pending:
        self._fallback_cross_user_pending = False
        if self._try_cross_user_recovery():
            self._propagate_cross_user_save_state()
            return 'recovered'
        return 'exhausted'

    return 'exhausted'
```

### 2.3 Phase 3 : Cross-user recovery (copie depuis un autre profil Dolphin)

**Fichier : `episode_mixin.py`**

```python
# NOUVEAU — Copie depuis un autre profil User de Dolphin
def _try_cross_user_recovery(self) -> bool:
    """Copy a valid save state file from another user profile, overwrite
    the corrupted one, then reload and verify.
    Returns True if recovery succeeded, False if all users are corrupted."""
    dolphin_dir = self._get_dolphin_base_dir()
    my_folder = self._get_user_folder_name()
    donor_folders = [f for f in self._list_all_user_folders(dolphin_dir)
                     if f != my_folder]

    for donor in donor_folders:
        for slot in slots_to_recover:
            ext = _SLOT_EXTENSIONS.get(slot, f".s{slot:02d}")
            donor_file = os.path.join(dolphin_dir, donor, "StateSaves", f"{_GAME_ID}{ext}")

            if not os.path.isfile(donor_file):
                continue
            if os.path.getsize(donor_file) < 1024:
                continue  # Suspiciously small — skip

            # Copy donor save state to our folder
            target_file = os.path.join(dolphin_dir, my_folder, "StateSaves", f"{_GAME_ID}{ext}")
            shutil.copy2(donor_file, target_file)

            # Reload and verify
            self._send_save_state_key(f'f{slot}')
            time.sleep(2.0)
            if self._verify_reload(1, 1) is True:
                return True
    return False
```

### 2.4 Propagation des save states fonctionnelles

**Fichier : `episode_mixin.py`**

```python
# NOUVEAU — Si F7 fonctionne et F5/F6 ont échoué, copie F7 → F5 et F6
def _propagate_working_save_state(self, working_slot: int):
    """Copy a working save state file to all earlier failed slots."""
    src_ext = _SLOT_EXTENSIONS.get(working_slot)
    src_file = os.path.join(save_dir, f"{_GAME_ID}{src_ext}")
    for failed_slot in self._failed_slots:
        if failed_slot == working_slot:
            continue
        dst_ext = _SLOT_EXTENSIONS.get(failed_slot)
        dst_file = os.path.join(save_dir, f"{_GAME_ID}{dst_ext}")
        shutil.copy2(src_file, dst_file)

# NOUVEAU — Après cross-user recovery, copie vers TOUS les slots locaux
def _propagate_cross_user_save_state(self):
    """After cross-user recovery, copy the recovered save state to ALL
    local slots (F5-F8) since they all failed."""
```

## ✅ 3. Isolation des environnements bloqués (multi-agent trainer)

### Problème
Un seul env avec une save state corrompue bloquait tout l'entraînement. L'ancien code levait un `RuntimeError` qui stoppait tous les agents d'un coup.

### Solution — Isolation gracieuse + recovery lazy

**Fichier : `multi_agent_trainer.py`**

**Avant :**
```python
# v0.5.6 — Un env bloqué → tout plante
for env_idx in range(self.env.num_envs):
    step_result = env.step(action)
    # Si l'env ne peut pas reload → RuntimeError → TOUS les agents stoppés
```

**Après :**
```python
# Isolation : l'env bloqué est "découplé" du training, les autres continuent

# 1. Détection : env coincé hors quête pendant N steps consécutifs
for env_chk in range(self.env.num_envs):
    if getattr(self.env.envs[env_chk], '_isolated', False):
        continue  # Already isolated — skip
    chk_info = infos[env_chk]
    if chk_info.get('quest_ended_screen') or chk_info.get('quest_ended_before_action'):
        self._env_consecutive_quest_end[env_chk] += 1
        if self._env_consecutive_quest_end[env_chk] >= self._env_stuck_threshold:
            self.env.envs[env_chk]._isolated = True
            self.env.envs[env_chk]._init_fallback_recovery()
            # "ISOLATING (other agents continue)"

# 2. Pendant collect : les envs isolés retournent des données factices
if getattr(_env, '_isolated', False):
    new_observations_list.append(dummy_obs)  # Last known obs
    rewards_list.append(0.0)                 # Zero reward
    dones_list.append(False)                 # Never "done"
    infos_list.append({'isolated': True})    # Flag for GUI
    agents_used.append(-2)                   # -2 = isolated sentinel
    continue  # Skip step() entirely — no blocking

# 3. Recovery lazy : toutes les 5s, tente le prochain fallback slot
for env_chk in range(self.env.num_envs):
    _env_chk = self.env.envs[env_chk]
    if not getattr(_env_chk, '_isolated', False):
        continue
    _last_attempt = getattr(_env_chk, '_last_recovery_attempt', 0.0)
    if _current_time - _last_attempt < 5.0:
        continue  # Rate limit: 1 attempt per 5 seconds

    result = _env_chk._attempt_next_fallback()
    if result == 'recovered':
        _env_chk._isolated = False
        self._env_consecutive_quest_end[env_chk] = 0
        # Force a fresh reset to get a clean observation
        _reset_result = _env_chk.reset()
        # Update observations array
    elif result == 'exhausted':
        # "Stays isolated until manual intervention."
        pass

# 4. Sécurité : si TOUS les envs sont isolés → stop propre
active_envs = sum(
    1 for i in range(self.env.num_envs)
    if not getattr(self.env.envs[i], '_isolated', False)
)
if active_envs == 0:
    raise RuntimeError(
        "Training stopped: all environments have corrupted "
        "save states. Please re-save valid save states."
    )
```

def sanitize_info(info_dict: dict) -> dict:
    """
    Règles complètes :
    1. Préserver 'episode' dict {r, l, t} pour SB3
    2. Garder reward_breakdown mais None → 0.0
    3. None → défaut selon nom clé (int/float/bool)
