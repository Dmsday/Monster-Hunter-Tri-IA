## ✅ 1. Save state reload individuel par instance

### Problème (v0.5.5)
```python
# episode_mixin.py — OLD : reload via pynput.Key.f5 (focus global)
def _reload_save_state(self):
    self.keyboard.press(Key.f5)   # ← Envoyé à la fenêtre active OS
    time.sleep(0.1)               #   → n'importe quelle instance recevait F5
    self.keyboard.release(Key.f5)
```

### Maintenant (v0.5.6)
```python
# episode_mixin.py — PostMessage ciblé vers MHTri-N de CET agent
def _send_save_state_key(self, slot_key: str) -> bool:
    """Envoie via controller.send_save_state_key() → PostMessage vers MHTri-{instance_id}."""
    if self.controller and self.controller.is_connected:
        self.controller.send_save_state_key(slot_key)  # Ciblé sur CETTE instance
        return True

# Résultat : agent 0 recharge F5 sur MHTri-0, agent 1 recharge F5 sur MHTri-1
# Sans que l'un influence l'autre
```

## ✅ 2. Fallback slots automatique pour save states expirées
```python
# episode_mixin.py — Essaie les slots dans l'ordre si le slot primaire est expiré
FALLBACK_SLOTS = [6, 7, 8]

def _reload_save_state(self):
    slots_to_try = [self.save_state_slot] + FALLBACK_SLOTS
    for slot in slots_to_try:
        result = self._verify_reload(attempt, max_attempts)
        if result == 'expired':
            # Quest_time <= 10 dans ce slot → essayer le suivant
            continue
        if result is True:
            return True
```

## ✅ 3. `_verify_reload()` — Vérification post-reload robuste
```python
# episode_mixin.py — Vérifie MAP, deaths et quest_time après chaque reload
def _verify_reload(self, attempt, max_attempts):
    state = self.memory.read_game_state()
    current_map = state.get('current_map')
    deaths      = state.get('death_count', 0) or 0
    quest_time  = state.get('quest_time', 5400)

    if current_map == 100 and deaths < 3:
        if quest_time is not None and quest_time <= 10:
            return 'expired'  # Slot inutilisable → essayer suivant
        return True           # OK
    return None               # Retry
```

## ✅ 4. Isolation des récompenses par instance

### Problème
Le `RewardCalculator` et l'`ExplorationTracker` étaient instanciés une fois et partagés. En multi-instance, les morts ou découvertes d'une instance affectaient les statistiques d'une autre.

### Solution
```python
# mh_env.py — Chaque environnement crée sa propre instance de reward_calc
def _init_reward_calculator(self):
    self.reward_calc = MonsterHunterRewardCalculator()
    # ← Une instance par environnement, jamais partagée
    if self.memory is not None:
        self.memory.reward_calc = self.reward_calc
        # ExplorationTracker également individuel (contenu dans reward_calc)
```

## ✅ 5. Isolation DME (dolphin-memory-engine) par PID

### Problème
DME est un singleton C++ global : il ne peut être accroché qu'à **un** processus Dolphin à la fois. En multi-instance, toutes les instances lisaient depuis le premier Dolphin trouvé.

### Solution
```python
# dynamic_memory_reader.py — DolphinDirectReader : lecteur indépendant par PID
class _DolphinDirectReader:
    """
    Lit la RAM Dolphin directement via ReadProcessMemory.
    Traduction d'adresse : MEM1 (0x80000000) et MEM2 (0x90000000)
    sans passer par DME (singleton). Un reader par PID = isolation garantie.
    """
    def __init__(self, pid: int):
        self._pid = pid
        self._connect()    # OpenProcess(PROCESS_ALL_ACCESS, pid)
        self._discover()   # Scan VirtualQueryEx → trouver MEM1 et MEM2

# MemoryReader utilise _DolphinDirectReader si target_pid est fourni
if self._target_pid is not None:
    self._direct = _DolphinDirectReader(self._target_pid)
    # → read_value() passe par _direct (indépendant) plutôt que DME (partagé)
```

## ✅ 6. Verrou global DME pour mode fallback
```python
# dynamic_memory_reader.py — Protection contre les re-hooks concurrents
_dme_global_lock = threading.Lock()  # Sérialise tous les appels DME

def read_value(self, address_name):
    if self._direct is not None:
        # Fast path : lecteur direct par PID, pas de lock nécessaire
        return self._direct.read_float(addr_val)
    # Fallback : DME partagé, lock obligatoire
    with _dme_global_lock:
        return dme.read_float(addr_val)
```
