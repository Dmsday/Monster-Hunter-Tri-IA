# 🔧 CHANGELOG - v0.6.6

## 📋 Résumé

Correction de tous les bugs de logs en multi-instance : doublons dans les fichiers, mauvais routage entre agents, handlers qui survivent trop longtemps entre runs.

---

## ✅ 1. Correction : logs d'un agent écrits dans les fichiers d'un autre

### Problème (v0.6.5)
```python
# info/advanced_logging.py — Les file handlers étaient attachés à TOUS les mh_* loggers
# sans filtre → agent 0 et agent 1 s'écrivaient mutuellement dans leurs fichiers
register_file_handler(ch)  # ch attaché à tous les loggers → mauvais agent recevait les logs
```

### Correction (v0.6.6)
```python
# Les handlers console.log des envs utilisent _EnvContextFilter
# ET les handlers errors.log utilisent AgentContextFilter
# → Chaque fichier ne reçoit QUE ses propres records

# console.log → _EnvContextFilter(agent_id, instance_id)
# errors.log  → AgentContextFilter(agent_id)
# reward_debug.log → pas de filtre (appels explicites uniquement, jamais global)
if _console_filter:
    ch.addFilter(_console_filter)
if _agent_filter:
    eh.addFilter(_agent_filter)
```

## ✅ 2. Correction : EnvContext non défini pendant SB3 learn()

### Problème
```python
# Pendant SB3 learn(), EnvContext n'était jamais défini
# → _EnvContextFilter rejetait tous les logs car current_env = None
# → console.log env_0/ restait vide pendant l'entraînement single-instance
```

### Correction
```python
# info/advanced_logging.py — _on_step() définit explicitement EnvContext
def _on_step(self) -> bool:
    for _env_idx, (_info, ...) in enumerate(zip(...)):
        if self.agent_id is not None:
            AgentContext.set_current_agent(self.agent_id)
        EnvContext.set_current_env(_env_idx)  # ← AJOUTÉ

        _orig = self.training_logger
        self.training_logger = _env_logger
        self._process_step(...)
        self.training_logger = _orig

        EnvContext.clear()  # ← Nettoyage après traitement (évite le bleed)
```

## ✅ 3. Correction : handlers dupliqués au redémarrage

### Problème
```python
# Quand on relançait train.py sans fermer Python,
# les handlers du run précédent restaient dans _GLOBAL_FILE_HANDLERS
# → Chaque message était écrit 2x (ou 3x) dans les fichiers
```

### Correction
```python
# train/logging_setup.py — teardown_loggers() retire les vieux handlers
def teardown_loggers(training_loggers: list) -> None:
    for tl in training_loggers:
        for handler in getattr(tl, '_file_handlers', []):
            for name in list(logging.root.manager.loggerDict.keys()):
                if name.startswith('mh_'):
                    lg = logging.getLogger(name)
                    if handler in lg.handlers:
                        lg.removeHandler(handler)
            if handler in _GLOBAL_FILE_HANDLERS:
                _GLOBAL_FILE_HANDLERS.remove(handler)
```

## ✅ 4. Correction : stdout dupliqué en mode multi-agent

### Problème
```python
# module_logger.py — propagate=True causait une remontée au root logger
# En multi-agent, les logs apparaissaient 2x dans la console
```

### Correction
```python
# module_logger.py — propagate=False dès qu'un file handler est attaché
for file_handler in _GLOBAL_FILE_HANDLERS:
    if file_handler not in logger.handlers:
        logger.addHandler(file_handler)
        logger.propagate = False  # ← Évite doublon stdout
```

## ✅ 4. `log_reward_step()` — Deux niveaux de détail (top + sous-catégories)

```python
# info/advanced_logging.py — Breakdown reward lisible dans reward_debug.log
def log_reward_step(self, reward, breakdown, breakdown_detailed=None, ...):
    top_parts = "  ".join(
        f"{cat}={val:+.4f}"
        for cat, val in sorted(breakdown.items(), key=lambda x: abs(x[1]), reverse=True)
    )
    # Sous-catégories non-nulles seulement (pour garder readable)
    detail_parts = "  ".join(
        f"{subcat}={val:+.4f}"
        for subcat, val in sorted(breakdown_detailed.items(), ...)
        if val != 0.0
    )
    line = f"[EP:{e:>4} STEP:{s:>7}] total={reward:+.4f} || {top_parts}"
    if detail_parts:
        line += f"\n                              └─ details: {detail_parts}"
```

## ✅ 6. `_log_error_all()` — Propagation aux tous les loggers disponibles

```python
# train/runner.py — Si une erreur survient, TOUS les loggers la reçoivent
def _log_error_all(error, context, training_loggers, training_logger):
    """Log une erreur dans chaque TrainingLogger disponible."""
    if training_loggers:
        for tl in training_loggers:
            if tl.agent_id is not None:
                AgentContext.set_current_agent(tl.agent_id)
            tl.log_error(error, context=context)
    elif training_logger:
        training_logger.log_error(error, context=context)
# → Même si le crash vient d'un agent X, tous les fichiers errors.log sont informés
```

# train/dolphin.py — Les dossiers temp/ et debug/ ont leur .gitignore auto-créé
def _ensure_gitignore(directory: str, patterns=None):
    os.makedirs(directory, exist_ok=True)
    gi = os.path.join(directory, ".gitignore")
    if not os.path.exists(gi):
        with open(gi, 'w') as f:
            for p in (patterns or ["*"]):
                f.write(f"{p}\n")
            f.write("!.gitignore\n")
